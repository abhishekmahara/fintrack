# FinTrack Dashboard

## Overview

FinTrack Dashboard is a responsive personal finance interface built for monitoring income, expenses, balances, and transaction activity in a clear, modern workspace. The app combines dashboard summaries, transaction management, and visual insights to make financial trends easier to understand at a glance.

## Features

- Dashboard summary cards for balance, income, expenses, highest spending category, monthly comparison, and savings calculation
- Interactive charts for monthly income versus expense trends and category-based spending breakdown
- Transaction management with search, filtering, and admin-only transaction entry
- Responsive layout improvements for mobile screens, including a collapsible sidebar and scrollable transaction tables
- Empty-state handling when no transactions are available
- Local persistence for transactions and user role using browser storage

## Tech Stack

- React 19
- Redux Toolkit
- React Redux
- Vite
- Tailwind CSS 4
- Recharts

## Setup

### Prerequisites

- Node.js 18 or later
- npm

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
